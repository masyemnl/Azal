# Bonnen Coffee - Premium Coffee E-commerce Website

A beautiful, responsive e-commerce website for selling premium coffee beans. Built with modern HTML5, CSS3, and JavaScript.

## 🌟 Features

### 🛍️ E-commerce Functionality
- **Product Catalog**: 6 premium coffee varieties with detailed descriptions
- **Shopping Cart**: Add/remove items, quantity management, persistent storage
- **Checkout**: PayPal integration for secure payments
- **Product Pages**: Individual detailed pages for each coffee blend

### 🎨 Design & User Experience
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Modern UI**: Clean, professional coffee shop aesthetic
- **Smooth Animations**: Hover effects, transitions, and visual feedback
- **Accessibility**: ARIA labels, keyboard navigation, screen reader friendly

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local web server (optional, for development)

### Installation
1. Download or clone this repository
2. Open `index.html` in your web browser
3. For development, use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```

## 🛠️ Customization

### Adding New Products
1. Create a new product page (copy from existing product page)
2. Update the product information in the new page
3. Add the product to the main page's product grid
4. Update the JavaScript cart functionality if needed

### Styling
- Main styles are in `css/styles.css`
- Uses CSS custom properties (variables) for easy theming
- Color scheme can be changed by modifying the `:root` variables

### PayPal Integration
To enable PayPal payments:
1. Sign up for a PayPal Developer account
2. Create a new application
3. Replace `YOUR_CLIENT_ID` in `cart.html` with your actual client ID
